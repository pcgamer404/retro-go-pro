Place the following files from your Fallout 2 installation (GOG / Steam / CD) into this directory:

Required:
- master.dat
- critter.dat

Optional (if present in your installation):
- data/ folder (scripts, text, sound, etc.)
- patch000.dat (if using official / unofficial patches)

When Fallout 2 is launched for the first time, fallout-go will automatically create an optimized fallout.cfg with art_cache_size=2MB configured for ESP32-S3 PSRAM.
