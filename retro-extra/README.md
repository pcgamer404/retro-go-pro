# retro-extra

Neo Geo Pocket / Neo Geo Pocket Color (RACE core, from pjcau).

| System | Tab id |
|---|---|
| NGP / NGPC | `ngp` (also `ngpc`) |

- Controls: D-pad, A/B, START = Option. MENU / OPTION = Retro-Go menus.
- Kept as its own app because RACE's static tables use ~26 KB of internal RAM that every retro-core emulator would otherwise pay for.
- Stella moved to `atari-core`; Arcade 3D is the standalone `arcade3d` app.
