Find (around line 38-41):

static int sig_list[] = {
	SIGHUP, SIGINT, SIGQUIT, SIGPIPE, SIGALRM, SIGTERM, SIGCHLD, SIGWINCH,
	SIGVTALRM, SIGPROF, 0

Replace with:

static int sig_list[] = {
	SIGHUP, SIGINT, SIGQUIT, SIGPIPE, SIGALRM, SIGTERM, SIGCHLD, SIGWINCH,
	0
};

(SIGVTALRM/SIGPROF aren't defined by this toolchain's newlib signal.h --
they're timer/profiling signals irrelevant on ESP32 anyway, safe to drop
from this thread-setup mask list.)
